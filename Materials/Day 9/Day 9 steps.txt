Next, we ran the following 3 commands to populate our package and zip it:

Copy-Item -Recurse app package\app
Copy-Item lambda_handler.py package\lambda_handler.py
Compress-Archive -Path package\* -DestinationPath lambda_deployment.zip -Force

Next, we created our AWS Lambda function directly in the terminal:

aws lambda create-function `
  --function-name robopulse-api `
  --runtime python3.12 `
  --architectures x86_64 `
  --role <arn-of-robopulse-lambda-execution-role> `
  --handler lambda_handler.handler `
  --zip-file fileb://lambda_deployment.zip `
  --timeout 30 `
  --memory-size 256 `
  --region us-east-1


Next, we generated our secret_key using this command:
python -c "import secrets; print(secrets.token_hex(32))"

copy the results

Next, we created our env file for our lambda function to read our environment variables
created backend\lambda-env.json:
```
{
	"Variables" : {
	"DATABASE_URL" : "postgresql+asyncpg://<user>:<password>@<rds-endpoint>:5432/robopulse",
	"SECRET_KEY" : "<your-generated-key-copied-from-terminal>",
	"FRONTEND_ORIGIN" : "http://localhost:5173"
}
}

```

We applied those variables to our lambda function using the following command:

aws lambda update-function-configuration --function-name <your-lambda-function-name> --environment file://lambda-env.json
